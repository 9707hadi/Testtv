# Arshia TV (Web)

وب‌تلویزیون زنده ارشیا تی‌وی برای GitHub Pages.

## انتشار روی GitHub Pages
1. یک ریپوی جدید بساز (مثلاً `arshiya_tv`)
2. محتویات این پوشه را push کن
3. Settings → Pages → Branch `main` → folder `/ (root)`
4. آدرس: `https://USERNAME.github.io/arshiya_tv/`

## فایل‌ها
- `index.html` رابط
- `style.css` ظاهر
- `app.js` پخش و لیست
- `channels.json` ۳۳۳ شبکه با server1..n

برند فقط ارشیا تی‌وی است.
